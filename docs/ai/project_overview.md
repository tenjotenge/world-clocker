# Project Overview

## Purpose

World-Clocker probes the stable, independently distinguishable decision policies
a model can express under different prompts. The motivating Model Worlds metaphor
gives those measured distinctions a geographic interpretation. The benchmark
observes choices on authored tasks and keeps rank, entropy, stability, and
distances available alongside the metaphor.

## Scope

The Python CLI supports reproducible local and OpenAI-compatible inference,
deterministic mock providers, SQLite manifests and observations, and offline
analysis. The v0.2 protocol distinguishes strong steering, weak steering, and
neutral controls. Population calibration v2 uses only the stable weak-prompt
repertoire. Model size, release date, architecture, and quantization can explain
differences in later analysis and carry no scoring weight.

## Success criteria

Produce reproducible profiles under matched conditions and disclose uncertainty
and missing coverage. Keep the geographic index provisional. A city label
describes the closest population in a sourced catalog and does not estimate
human simulation capacity.
